```bash

```

# ✅ Event Organizer – Vanilla JS, HTML & CSS CRUD Project

This is a events management web app built to practice and demonstrate **JavaScript, HTML, and CSS** skills.  
The interface allows users to create, edit, delete,events in a clean and organized layout with modal interaction.

🧠 Ideal for beginners learning CRUD operations with a fake API (JSON Server).
